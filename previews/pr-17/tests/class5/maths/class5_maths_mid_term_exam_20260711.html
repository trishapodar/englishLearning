Q5. The difference between the two digits must be exactly 1.
Marking Scheme / Steps: Let the two different digits chosen be a and b, where a > b.
The two 2-digit numbers formed are 10a + b and 10b + a.
Subtracting the smaller number from the larger number gives: (10a + b) - (10b + a) = 9a - 9b = 9(a - b).
For the result to be a 1-digit number, the value of 9(a - b) must be less than 10.
Since a and b are different digits, the minimum value of (a - b) is 1.
If a - b = 1, then 9(a - b) = 9 x 1 = 9, which is a 1-digit number.
If a - b ≥ 2, then the result will be 18 or more, which is a 2-digit number.
Thus, the difference between the two digits must be exactly 1 (i.e., they must be consecutive digits like 3 and 4, or 7 and 8).
