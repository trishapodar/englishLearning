Q1. (b) 4a² - 12ab + 9b²
Marking Scheme / Steps: Step: (2a - 3b)² = (2a)² - 2*(2a)*(3b) + (3b)² = 4a² - 12ab + 9b².
Q2. (a) -1260
Marking Scheme / Steps: Step: Here a = -12, b = 7, c = 5. Since a + b + c = -12 + 7 + 5 = 0, we have a³ + b³ + c³ = 3abc = 3 * (-12) * 7 * 5 = -1260.
Q3. (c) 23
Marking Scheme / Steps: Step: (x + 1/x)² = x² + (1/x²) + 2
5² = x² + (1/x²) + 2
25 = x² + (1/x²) + 2 ⇒ x² + (1/x²) = 23.

Q6. Factorise 4x² + 9y² + ...
Marking Scheme / Steps: Recognizing Identity: Express as (2x)² + (3y)² + (-4z)² + 2*(2x)(3y) + 2(3y)(-4z) + 2(2x)*(-4z) [1 Mark]
Final Factorised Form: (2x + 3y - 4z)² or (2x + 3y - 4z)(2x + 3y - 4z) [1 Mark]

SECTION C: Medium Answer Questions

Q7. Value of x² + y² + z²
Marking Scheme / Steps: Using Identity: (x + y + z)² = x² + y² + z² + 2*(xy + yz + zx) [1 Mark]
Substituting values: 9² = x² + y² + z² + 2*(26) [1 Mark]
Solving: 81 = x² + y² + z² + 52 ⇒ x² + y² + z² = 81 - 52 = 29 [1 Mark]
Q8. Verify identity
Marking Scheme / Steps: Expanding RHS: RHS = (1/2) * (x + y + z) * [(x² - 2xy + y²) + (y² - 2yz + z²) + (z² - 2zx + x²)] [1 Mark]
Combining terms: = (1/2) * (x + y + z) * [2x² + 2y² + 2z² - 2xy - 2yz - 2zx] [1 Mark]
Simplifying factor of 2: = (x + y + z) * (x² + y² + z² - xy - yz - zx) = x³ + y³ + z³ - 3xyz = LHS. Hence Verified. [1 Mark]

SECTION D: Case-Based Integrated Question

Q9. Cubic storage structure
Marking Scheme / Steps: (i) Factor Theorem (1.5 Marks):
Substitute x = 1: P(1) = (1)³ - 6(1)² + 11(1) - 6 = 1 - 6 + 11 - 6 = 0. Since P(1) = 0, (x - 1) is a factor.
(ii) Division to find Quadratic Quotient (1.5 Marks):
Divide (x³ - 6x² + 11x - 6) ÷ (x - 1) = x² - 5x + 6.
(iii) Complete Factorization (2 Marks):
Factorise x² - 5x + 6 = (x - 2)(x - 3).
Dimensions: Length = (x - 1), Breadth = (x - 2), Height = (x - 3).
(iv) Physical Volume at x = 5 cm (1 Mark):
Length = 4 cm, Breadth = 3 cm, Height = 2 cm.
Volume = 4 * 3 * 2 = 24 cm³ (or P(5) = 125 - 150 + 55 - 6 = 24 cm³).
