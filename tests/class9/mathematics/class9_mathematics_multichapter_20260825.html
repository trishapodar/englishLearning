SECTION B: VERY SHORT ANSWER QUESTIONS (6 MARKS)

Q7. Rationalisation
Model Answer & Marking:
Step 1: Multiply numerator and denominator by the conjugate (√3 - √2): [5 / (√3 + √2)] × [(√3 - √2) / (√3 - √2)] [0.5 Mark]
Step 2: Apply identity (a + b)(a - b) = a² - b² in denominator: = [5(√3 - √2)] / [(√3)² - (√2)²] [0.5 Mark]
= [5(√3 - √2)] / (3 - 2) [0.5 Mark]
Step 3: Final answer: = 5(√3 - √2) OR 5√3 - 5√2 [0.5 Mark]
Q8. Zero of Linear Polynomial
Model Answer & Marking:
Step 1: Since x = 3 is a zero, p(3) = 0: 2(3) + 3k - 15 = 0 [0.5 Mark]
Step 2: Simplify equation: 6 + 3k - 15 = 0 => 3k - 9 = 0 [0.5 Mark]
Step 3: Solve for k: 3k = 9 => k = 9/3 = 3 [1 Mark]
Q9. Probability of Drawing Balls
Model Answer & Marking:
Total number of possible outcomes = 5 + 8 + 7 = 20 [0.5 Mark]
(i) Probability of White ball: Number of white balls = 8. P(White) = 8/20 = 2/5 (or 0.4) [0.5 Mark + 0.25 Mark for simplification]
(ii) Probability of Not a red ball: Number of non-red balls = 8 + 7 = 15. P(Not Red) = 15/20 = 3/4 (or 0.75) [0.75 Mark]

Q10. Algebraic Identities Evaluation
Model Answer & Marking (3 Marks):
(i) 103 × 107 [1.5 Marks]: Write as: (100 + 3)(100 + 7) [0.5 Mark]. Apply identity: (x + a)(x + b) = x² + (a + b)x + ab = (100)² + (3 + 7)(100) + (3 × 7) [0.5 Mark]. = 10000 + (10 × 100) + 21 = 11,021 [0.5 Mark]
(ii) (99)³ [1.5 Marks]: Write as: (100 - 1)³ [0.5 Mark]. Apply identity: (a - b)³ = a³ - 3a²b + 3ab² - b³ = (100)³ - 3(100)²(1) + 3(100)(1)² - (1)³ [0.5 Mark]. = 1,000,000 - 30,000 + 300 - 1 = 970,299 [0.5 Mark]
Q11. Heron’s Formula & Perimeter
Model Answer & Marking (3 Marks):
(i) Area of Triangular Park [2 Marks]: Sides: a = 120 m, b = 80 m, c = 50 m. Semi-perimeter s = (a + b + c)/2 = 250/2 = 125 m [0.5 Mark]. s - a = 5 m, s - b = 45 m, s - c = 75 m [0.5 Mark]. Area = √[s(s - a)(s - b)(s - c)] = √[125 × 5 × 45 × 75] = 375√15 m² [1 Mark]
(ii) Wire required for fencing [1 Mark]: Perimeter of park = 250 m. Length of wire = Perimeter - Gate space = 250 - 3 = 247 m [1 Mark]
Q12. Arithmetic Progression
Model Answer & Marking (3 Marks):
(i) Finding a and d [1.5 Marks]: a4 = a + 3d = 18 (1) [0.5 Mark], a10 = a + 9d = 42 (2) [0.5 Mark]. Subtracting (1) from (2): 6d = 24 => d = 4 [0.25 Mark]. Substitute d = 4 in (1): a + 12 = 18 => a = 6 [0.25 Mark]
(ii) Sum of first 20 terms [1.5 Marks]: Sn = (n/2)[2a + (n - 1)d]. S20 = (20/2)[2(6) + (20 - 1)(4)] [0.5 Mark]. = 10[12 + 76] [0.5 Mark]. = 10 × 88 = 880 [0.5 Mark]

SECTION D: LONG ANSWER & CASE STUDY QUESTIONS (9 MARKS)

Q13. Option (A)
Model Answer & Marking (5 Marks):
(i) Value of a² + b² + c² [2 Marks]: Identity: (a + b + c)² = a² + b² + c² + 2(ab + bc + ca) [0.5 Mark]. Substitute values: (9)² = a² + b² + c² + 2(26) [0.5 Mark]. 81 = a² + b² + c² + 52 [0.5 Mark]. a² + b² + c² = 29 [0.5 Mark]
(ii) Value of a³ + b³ + c³ - 3abc [3 Marks]: Identity: a³ + b³ + c³ - 3abc = (a + b + c)[a² + b² + c² - (ab + bc + ca)] [1 Mark]. Substitute values: = 9 × [29 - 26] [1 Mark]. = 9 × 3 = 27 [1 Mark]
Q13. Option (B)
Model Answer & Marking (5 Marks):
(i) Factorise 8x³ + 27y³ + 36x²y + 54xy² [2.5 Marks]: Rewrite terms: (2x)³ + (3y)³ + 3(2x)²(3y) + 3(2x)(3y)² [1 Mark]. Notice form: a³ + b³ + 3a²b + 3ab² = (a + b)³ [0.5 Mark]. = (2x + 3y)³ = (2x + 3y)(2x + 3y)(2x + 3y) [1 Mark]
(ii) Factorise 27x³ + y³ + z³ - 9xyz [2.5 Marks]: Rewrite terms: (3x)³ + (y)³ + (z)³ - 3(3x)(y)(z) [1 Mark]. Apply identity: a³ + b³ + c³ - 3abc = (a + b + c)(a² + b² + c² - ab - bc - ca) [0.5 Mark]. = (3x + y + z)(9x² + y² + z² - 3xy - yz - 3zx) [1 Mark]
Q14. Case Study Question
Model Answer & Marking (4 Marks):
(i) Geometric Shape [1 Mark]: Adjacent side AB is along horizontal line y = 2, and side AD is along vertical line x = 2 (perpendicular at 90°). Opposite sides are equal (6 and 5). Therefore, ABCD is a Rectangle. [1 Mark] (0.5 for name + 0.5 for reason)
(ii) Dimensions [1 Mark]: Length AB = 8 - 2 = 6 grid units = 60 m [0.5 Mark]. Width BC = 7 - 2 = 5 grid units = 50 m [0.5 Mark]
(iii) Perimeter [1 Mark]: 2 × (Length + Width) = 2 × (60 m + 50 m) = 220 m [1 Mark]
(iv) Area [1 Mark]: Length × Width = 60 m × 50 m = 3,000 m² [1 Mark]
